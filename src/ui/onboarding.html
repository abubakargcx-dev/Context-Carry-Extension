First-run setup

Get a free key, then carry chats between models

Keys are stored only on this computer. Skip any step; you can finish later from Settings.

1. Groq API key (recommended)

  1. Open console.groq.com/keys and sign in.
  2. Create an API key and copy it.
  3. Paste it below and save. This is the primary summarizer — fast and free-tier.

2. OpenRouter key (optional fallback)

  1. Open openrouter.ai/keys.
  2. Create a key. Free models are used by default (openrouter/free).
  3. Paste it below. Context Carry uses this if Groq fails.

3. How you use it

  1. Open a ChatGPT, Claude, or Gemini conversation (or any page, then highlight the chat).
  2. Click the Context Carry icon to open the side panel.
  3. Choose Last exchange for a quick handoff, or Summarize full chat for the whole thread.
  4. Copy the handoff and paste it into a new chat — same product or a different one.

4. Done

You can reopen this guide from Settings anytime. Saved contexts never leave this browser unless you export them.
